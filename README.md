ScrollsSMP v10: animated Sonic Boom projectile, grappling chain, persistent Guardian Heart, stronger Ice Bubble, v9 effects and Words system. Build via GitHub Actions. This source has not been live-tested in Minecraft. Resource pack must be installed client-side.

v19: /withdraw 3, /withdraw words 3, /words withdraw 3, /reroll <player> (OP), /repair [all] (OP). If another plugin claims a command, use /scrollssmp:withdraw 3 or /scrollssmp:repair.

Admin utility items: /give reroller, /give words, /give reroller 3, /give words 3 (player shortcuts). /scrollgive reroller 3 <player> or /scrollgive words 3 <player> works for console too. These are physical items, not Word balance changes.

## Words withdrawal
Use `/scrollwithdraw 3` to avoid command collisions with other plugins. `/words withdraw 3` and `/withdraw 3` are also supported. You must retain at least one Word.

Admin reroll: `/scrollreroll <onlineplayer>` or `/scrollssmp:reroll <onlineplayer>` (requires OP). Offhand scrolls supported.
