ScrollsSMP TEST 1 - Paper 1.21.11 / Java 21

Contains ONLY Sculk and Speed scrolls.
Build using GitHub Actions (already included in .github/workflows/build.yml).
Upload built ScrollsSMP-2.0.0-test1.jar into Lagless Hosting /plugins, removing ALL earlier ScrollsSMP jar versions first.
Install ScrollsSMP-Test-ResourcePack.zip locally via Minecraft Options > Resource Packs (do not unzip the resource pack).
Commands (OP only):
/scroll give YourMinecraftName sculk
/scroll give YourMinecraftName speed

Controls: right-click = ability 1, sneak + right-click = ability 2.
Hold scroll in main hand for passives. True invisibility hides the entire player from other clients (not from own first-person camera).
13 hearts means 26 maximum health while Sculk Scroll is held. When unequipped, original max health returns.
Frenzy: +60% attack speed attribute and +35% melee damage for 6s.
Lightning: 5% chance on a melee hit, five cosmetic lightning strikes around the player; no damage to anybody.

KNOWN LIMITATIONS: This project has not been compiled or in-game tested in this environment. Other plugins altering max health, player visibility, or attack speed can conflict.
